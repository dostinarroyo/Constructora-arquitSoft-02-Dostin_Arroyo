Los archivos `.mmd` son las fuentes Mermaid editables; al abrirlos en GitHub se
verá su texto. Los archivos SVG de nivel 1 a 4 son fuentes vectoriales
editables y base de sus exportaciones PNG. Las exportaciones gráficas están en
la carpeta [`img`](../README.md) y se insertan en los documentos para que
aparezcan como diagramas al consultarlos en GitHub. La arquitectura inicial se
inserta en formato SVG para conservar la nitidez al ampliarla. Mantener
sincronizadas las fuentes y sus imágenes.
