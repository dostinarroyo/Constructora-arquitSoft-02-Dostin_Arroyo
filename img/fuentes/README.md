Los archivos `.mmd` son las fuentes Mermaid editables; al abrirlos en GitHub se
verá su texto. Las exportaciones PNG correspondientes están en la carpeta
[`img`](../README.md) y se insertan en los documentos para que aparezcan como
gráficos al consultarlos en GitHub. Mantener sincronizadas las fuentes y sus
imágenes.
