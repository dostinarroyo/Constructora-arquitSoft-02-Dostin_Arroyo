diagramas del proyecto.

| Fuente editable | Gráfico PNG |
|---|---|
| [arquitectura-inicial.drawio](./arquitectura-inicial.drawio) | [Arquitectura inicial con Clean Architecture](../arquitectura-inicial.png) (exportada desde Mermaid). |

| [arquitectura-componentes.mmd](./arquitectura-componentes.mmd) | [Componentes arquitectónicos](../arquitectura-componentes.png). |

| [nivel2-contenedores.svg](../nivel2-contenedores.svg) | [C4, nivel 2: contenedores de ConstructoraSys](../nivel2-contenedores.png), fuente vectorial editable y base de la exportación. |

Los archivos `.mmd` son las fuentes Mermaid editables; al abrirlos en GitHub se
verá su texto. Los archivos SVG de nivel 1 a 3 son fuentes vectoriales
editables y base de sus exportaciones PNG. Las exportaciones PNG están en la carpeta
[`img`](../README.md) y se insertan en los documentos para que aparezcan como
gráficos al consultarlos en GitHub. Mantener sincronizadas las fuentes y sus
imágenes.
