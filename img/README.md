# Diagramas del proyecto

Esta es la carpeta de recursos gráficos en la raíz del repositorio.

- Los archivos `.png` son exportaciones a color de los diagramas.
- Los archivos `.svg` son diagramas vectoriales que se mantienen nítidos al
  ampliarlos.
- [`fuentes/`](./fuentes/README.md) contiene los Mermaid (`.mmd`) editables y
  la fuente de draw.io.
