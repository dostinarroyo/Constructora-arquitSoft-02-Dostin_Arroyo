# Entregable 02: Análisis de caso – Arquitectura

## Sistema de gestión para una empresa constructora

Este entregable reúne el análisis del sistema y la propuesta inicial de
arquitectura para centralizar la gestión de proyectos, actividades, materiales,
personal, maquinaria, finanzas, reportes y usuarios de una empresa constructora.
