# Modelo C4

El modelo C4 presenta la arquitectura en distintos niveles, desde el contexto
del sistema hasta el detalle de un componente. Estos diagramas describen la
propuesta del sistema de gestión de la constructora; no representan una
implementación desplegada.

## Niveles

- [Nivel 1 - Contexto del sistema](./Nivel1-DiagramadeContextodelSistema.md): actores y sistema
  dentro de su entorno.
- [Nivel 2 - Contenedores](./Nivel2-DiagramadeContenedores.md): unidades ejecutables y
  almacenes de datos propuestos.
- [Nivel 3 - Componentes](./Nivel3-Diagrama-de-Componentes.md): responsabilidades dentro
  de la aplicación.
- [Nivel 4 - Código / diseño interno](./Nivel4-DiagramadeCodigo.md): diseño de clases y
  colaboración del caso de uso de salida de almacén.

Los diagramas se mantienen editables en Mermaid; sus fuentes .mmd están en
[img/fuentes](../../img/fuentes/README.md). Las relaciones y tecnologías
marcadas como propuestas deben confirmarse en el diseño detallado.
