# 02 - Historias de usuario

## Objetivo

Describir las principales necesidades de los usuarios del sistema para la gestión de proyectos, recursos, personal, maquinaria, materiales y aspectos financieros de una empresa constructora.

## Historias de usuario

| **ID** | **Historia de usuario** |
|---|---|
| **HU01** | Como administrador del sistema, quiero registrar, modificar y asignar roles a los usuarios, para controlar el acceso a las funciones de acuerdo con sus responsabilidades. |
| **HU02** | Como gerente general, quiero consultar un panel con información resumida de la empresa, para conocer el estado general de los proyectos y apoyar la toma de decisiones. |
| **HU03** | Como responsable de proyectos y obras, quiero registrar, modificar y consultar proyectos de construcción, para mantener organizada la información de las obras de la empresa. |
| **HU04** | Como gerente general o responsable de proyectos y obras, quiero consultar el estado y el porcentaje de avance de cada proyecto, para hacer seguimiento a la ejecución de las obras. |
| **HU05** | Como responsable de proyectos y obras, quiero registrar las actividades correspondientes a cada proyecto, para organizar y dar seguimiento al trabajo planificado en la obra. |
| **HU06** | Como responsable de proyectos y obras, quiero actualizar el avance de las actividades, para mantener informado el estado de ejecución de la obra. |
| **HU07** | Como responsable de almacén, quiero registrar los materiales utilizados en los proyectos, para identificar los recursos de almacén relacionados con cada obra. |
| **HU08** | Como responsable de almacén, quiero registrar las entradas y salidas de materiales, para mantener actualizado el control del almacén. |
| **HU09** | Como responsable de almacén o responsable de proyectos y obras, quiero consultar el stock disponible de los materiales, para conocer su disponibilidad para las necesidades de la obra. |
| **HU10** | Como responsable de personal, quiero registrar y actualizar la información de los trabajadores, para mantener organizada la información del personal de la empresa. |
| **HU11** | Como responsable de personal o responsable de proyectos y obras, quiero asignar trabajadores a proyectos o actividades, para identificar el personal asociado a cada obra. |
| **HU12** | Como responsable de proyectos y obras, quiero registrar la maquinaria y los equipos de la empresa, para mantener un inventario de los recursos disponibles para las obras. |
| **HU13** | Como responsable de proyectos y obras, quiero actualizar el estado y la asignación de los equipos, para conocer su disponibilidad y el proyecto en que se utilizan. |
| **HU14** | Como responsable financiero, quiero registrar el presupuesto asignado a cada proyecto, para disponer de una referencia financiera para el seguimiento de la obra. |
| **HU15** | Como responsable financiero, quiero registrar y consultar los gastos realizados en cada proyecto, para mantener el seguimiento de los costos de la obra. |
| **HU16** | Como gerente general, responsable de proyectos y obras o responsable de un área, quiero generar reportes de proyectos, materiales, personal, maquinaria y gastos, para revisar información consolidada que apoye el seguimiento y la toma de decisiones. |

## Observación

Estas historias representan las principales necesidades funcionales de los usuarios de la empresa constructora y sirven como base para la identificación y definición de los requisitos funcionales del sistema.
