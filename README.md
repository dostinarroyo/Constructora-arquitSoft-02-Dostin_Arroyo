la documentación de análisis, la propuesta arquitectónica, el diseño interno
y el modelo C4 del sistema de gestión para una empresa constructora.

## Alcance y estado

La solución documentada es una propuesta de arquitectura para centralizar la
gestión de proyectos, actividades, almacén, personal, maquinaria, finanzas,
reportes y usuarios. Las metas cuantitativas y tecnologías identificadas como
propuestas deben validarse con los responsables antes de considerarse
compromisos.

El repositorio está en fase de documentación: los modelos, flujos y contratos
son propuestas de diseño, no funcionalidades implementadas. La implementación
se abordará en una etapa posterior, cuando corresponda al alcance del curso.

## Presentación

La exposición y sus diapositivas son un entregable separado; este repositorio
contiene la documentación, no una presentación.
